## 一、先定判準

一張圖要留下，得通過三個測試：

| 測試 | 問法 | 不合格就 |
|---|---|---|
| **遮住測試** | 把圖遮住，讀者會不會誤解，或直接跳過這一段？ | 不是必備 |
| **替代測試** | 圖有沒有取代一段解釋？ | 只是把文字重畫一遍的，刪掉 |
| **出處測試** | 圖上每個字形、每個數字，指不指得出出處？ | 指不出來的不畫 |

**不畫的東西**：人物臉部、情節插畫、純裝飾、書中沒有的技術細節、漸層與寫實材質（與紙面、水墨的版式衝突）。寓言留白的地方，插畫會把它填死。

## 二、分級與編號

| 級 | 意思 | 什麼時候畫 |
|---|---|---|
| ★ | 沒有圖，多數讀者會誤解或跳過 | 首輪、第二輪 |
| ○ | 有圖可省一段解釋 | 第三輪 |
| △ | 氣氛、錦上添花 | 有空再說 |

- 編號 `圖 篇-序`，**篇**指 `novel/` 的九個檔案：煉丹 1、試丹 2、問診 3、裁衣 4、品丹 5、鑑丹 6、托付 7、服丹 8、過江 9。
- **圖號跟篇走，不跟頁走。** 電子書會把〈煉丹篇〉一～九另立為「緣起段」（`index.md` 第 0 列），所以 圖 1-1～1-4 落在緣起段、1-5 落在煉丹篇；日後把緣起段併回煉丹篇時，圖號不必重編。
- 圖號**由檔名決定**（`figs/1-1.svg`），正文與圖說都不手寫號碼。
- 「錨句」是改寫後用來找回位置的節錄，不是引用格式。

**總數：34 張候選（★26、○7、△1）。** 首輪 12、第二輪 14、第三輪 8。

## 八、插圖引起的正文改寫

插圖不是貼上去就好；有圖之後，正文要讓位。七條規矩：

1. **圖已說明的，正文不再重述。** 例：煉丹篇六「通用的木高而正；長在左邊的窄而長，捺收成點」——留「你看，左邊那一株的捺早就自己收成了點」就夠，其餘交給圖 1-3。
2. **每張圖在正文留一個自然的指涉**，不用「如下圖所示」。例：「（圖 1-3）」「左邊那一株（圖 1-3）」。
3. **圖說 ≤ 40 字，只說看哪裡，不下判斷。** 名句留在正文，不要搬進圖說重複一次。
4. **師父的話一字不改。** 改寫只動敘述層（這是服丹篇五自己立的規矩）。
5. **一圖一事。** 兩個概念就拆兩張，或把那一節拆開。
6. **圖放在該段之後、節末之前**；電子書是單欄，圖不可被下一個標題切斷。
7. **每篇 2–5 張。** 超過 5 張就回頭問：是不是有兩張在說同一件事。

三個具體的改寫點（示範，不是全部）：

| 位置 | 現在 | 有圖之後 |
|---|---|---|
| 品丹篇 七 | 分組、攤平、解框、對帳，四步全寫成句子 | 步驟收進圖 5-3；正文留「我看了很久，才看懂他的意思」與 14.5／43 兩個數 |
| 服丹篇 九 | 三把尺各說什麼、減法怎麼量 | 圖 8-4 畫三把尺與相減；正文留「三把尺一起錯了，錯得整整齊齊」 |
| 過江篇 七 | 一行 ACL 與師父的逐字解讀 | 圖 9-3 逐段標；正文留師父唸的那幾句，不再解釋語法 |

## 九、技術落地

### 產圖

- 新增 `tools/gen-novel-figs.ts`：讀 `out/lib-cjk-all.bin.gz` 與 `db/glyphwiki.db`，輸出 `novel/figs/*.svg`。
- 字形**一律用 `svgOf()`（KAGE 筆劃）**，不用系統字型截圖：䴺、㕻、𢆉、㪅 這類字多數系統字型沒有，會變豆腐。（已驗：圖上要用的四十幾個字，自家字庫全部找得到，`findGlyphIndex` 無一缺漏。）
- `novel/figs/` 是新目錄（SVG 原始檔）。它是來源資產，不是產物——README 的版控清單要加一列，否則下次「今日收工」會漏掉。
- 組字結果（寶缶支、街圭舞、初 的 礻、報土业）走 `composeFit`；「舊法一團墨」用幾何均分的 fallback 產生，不手繪。
- 數據圖的數字由 script 從 db 重算；正文常數（如 117,000 個框）集中在 `novel/figs/data.ts`，圖與圖說都讀同一份。

### 進書

`tools/gen-novel-html.ts` 目前**不認圖片**：`inline()` 會把 HTML 跳脫，`![…](…)` 只會原樣印出來。要加一個 block 規則：

```
![圖說](figs/1-1.svg)
```

→ 讀檔、去掉 `width`/`height`、把 `fill="#111"` 換成 `currentColor`、SVG 內的 id 加圖號前綴（避免同頁多張圖撞 id）、包成 `<figure><figcaption>`。
**單一 HTML 的承諾不變**：SVG 內嵌，不是外連。

### 版式

- 畫布寬 544（＝ `--measure` 34rem）；標籤 15–16px、線 1.4px；手機縮到 0.62 倍仍可讀。
- 圖只用 `currentColor` 與 `opacity`，四套主題自動適用；不要白底矩形。
- 字形圖的 viewBox 以 200 的倍數為單位，方便與現有 SVG 對齊。
- 圖說用次要色、小一級；圖與圖說之間留 0.6em。

### 驗收

- `bun run tools/gen-novel-html.ts --check` 之外，加三條：圖檔存在且是合法 SVG、SVG 內無外部參照與 `<text>` 罕用字、圖號連續且每篇至少一張。
- **字數統計要扣掉圖檔行**：`buildPages` 現在把 `![…](…)` 也算進字數，一行約 20 字，三十幾張會多算六、七百字，連帶影響目錄的「約幾分」。
- 跑一次生成，在日間／夜間兩套主題下各看一遍（黑底白字最容易漏）。
