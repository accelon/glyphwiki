# 《構形記》電子書設定

本檔是 `tools/gen-novel-html.ts` 的輸入。要改書的樣式、功能或章序，改這裡或改 `index.md`，
再跑一次生成程序即可；正文 `*.md` 的內容不動。

## 生成

```
bun run tools/gen-novel-html.ts            # 依本檔設定生成
bun run tools/gen-novel-html.ts --check    # 只檢查，不寫檔
bun run tools/gen-novel-html.ts --out novel/x.html
```

| 輸入 | 角色 |
|---|---|
| `novel/index.md` | 章序來源：取「電子書篇章順序」表（篇名／檔案／一句話） |
| `novel/ebook.md` | 本檔：書名、作者、主題、字級、功能開關 |
| `novel/*.md` | 正文各篇 |
| `novel/gouxingji.html` | 產物：單一網頁，離線可讀（檔名用拼音，全 ASCII） |

> 章序**不在本檔重複**。要調整順序、標題、目錄副標，改 `index.md` 那張表就好。
> 本檔只管「看起來怎樣、有什麼功能」。

> 每列 9 欄，依序是 CSS 變數：

## 版面

單欄，沒有任何畫外元素（沒有側欄、沒有側滑抽屜），所以不會有橫向捲動。

```
┌──────────────────────────────────────┐
│ ☰   構形記／第 1 / 9 篇   A−  A+  Aa │  ← 頂欄 sticky
├──────────────────────────────────────┤
│            （正文，置中限寬）          │
│                                      │
│          上一篇  ←→  下一篇           │
└──────────────────────────────────────┘
```

- **頂欄**：`☰` 開目次；中間是書名與「第 n / N 篇」；右邊是 `A−`、`A+`、`Aa`（閱讀設定）。`position:sticky`。
- **目次**：蓋住整個視窗的面板（`position:fixed`），只列篇名、篇次與約幾分。點即換篇並關閉。
- **閱讀設定**：由底部（手機）／中央（桌機）浮出的面板，完全不動正文版面。
- **換篇**：切換 `display` 並把捲動位置歸零；用瀏覽器返回上一頁時，回到該篇上次的閱讀位置。

## 風格

- 手機優先：單欄、可點區域 ≥ 40px、`safe-area-inset` 內距。
- 紙面質感：正文置於紙面板上；桌機時 `--measure`（34rem）置中、四周留白。
- 標題：篇名大字；篇內小節標題前綴一條強調色短豎線；`###` 為次級。
- 引文區塊：左側細線＋淡底。
- 表格：欄線極簡，數字欄右緣對齊，窄螢幕可橫向捲動。
- 強調：粗體用強調色；`*是為記。*` 這類單行斜體置中、轉為次要色。
- 分隔線：`---` 渲染為置中的細短線，不用滿版橫線。
- 章末：與下一篇之間留大段空白。
- 無外部資源：字型、圖示（以文字／CSS 繪製）、樣式、腳本全內嵌，離線可用。
- 無障礙：`lang="zh-Hant"`、面板有 `aria-modal` 與 `aria-expanded`、按鈕皆有 `aria-label`、尊重 `prefers-reduced-motion`。
